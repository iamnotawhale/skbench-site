skhub

SSH and API workbench for Linux

Terminals, hosts and SFTP next to a full API client —
one encrypted workspace on your machine,
with optional end-to-end sync between devices.

Download for Linux …

install sudo apt install ./skhub_amd64.deb

Terminal and SSH

  • Hosts, groups and credentials in an encrypted catalog
  • Split panes, local terminal, quick connect and snippets
  • SFTP browser and port forwarding
  • Optional end-to-end encrypted sync between machines

API client

  • REST and GraphQL requests, multipart uploads, OAuth 2.0
  • Collections and folders that share headers, auth, variables and scripts
  • Environments, dynamic variables, JavaScript scripts and assertions
  • JSONPath filter, search, code generation for many languages
  • Import from Bruno, Postman and OpenAPI, export to Bruno files

JSON and XML

  • Beautify, minify and sort keys, with the exact line and column of a syntax error
  • Compare two documents logically: key order, attribute order and whitespace do not count
  • Differences highlighted in both texts and listed with their paths
  • Copy a node, a property or its path from a context menu; nothing is written to disk
Debian / Ubuntu · amd64 · Public installers only — source stays private
